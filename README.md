# Liber

Liber is a private, landscape-first Android tablet book reader. It keeps a personal library on-device, with no login, sync, or tracking.

## Included

- Import multiple EPUB, PDF, MOBI, CBZ, and TXT files
- Search a local library
- Continue reading with saved progress
- Adjustable reading size
- Landscape tablet layout with a monochrome interface
- Open imported files through the device's compatible viewer

## Run

```bash
pnpm install
pnpm --filter @workspace/liber run dev
```

Open the project in Expo Go or use the Replit mobile preview.
